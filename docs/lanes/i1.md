## Not done as written

- `npm run db:reset`: Prisma (6.19) refuses `migrate reset` when an AI agent runs it and asks for
  the user's explicit consent through an environment variable. I did not set it. The dev database
  was already migrated, and `npm run db:seed` truncates every application table itself (that is
  its job: "wipes and recreates"), so the sequence `npm run problems:gen && npm run db:seed` gave
  the same clean state. Run `npm run db:reset` by hand if a from-scratch schema is wanted.
